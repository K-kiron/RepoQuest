# Changelog

## 0.1.0

- Ship the portable `repoquest` skill and optional Python CLI.
- Generate a standalone HTML debugging mystery with source citations, a scratchpad, progressive hints, and an explicit patch reveal.
- Reproduce the same behavior contract against before and after snapshots, rejecting execution errors, empty or skipped suites, different test selections, and stale evidence.
- Import selected files and license notices from two local Git commits without checkout or code execution.
- Include the self-authored cafe case, captured verification, keyboard-accessible demo, and narrow-screen layout.
- Write verification reports atomically, reserve the generated report name, and reject malformed references and incomplete report data.
- Provide a skill archive, standalone demo, Python wheel, checksums, installation documentation, and contribution guidance.

The first release supports curated Python cases using the standard library. It does not claim third-party historical cases, sandboxed execution, untested host compatibility, or measured learning gains.
